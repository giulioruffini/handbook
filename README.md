## For agents

Claude Code, Codex, Kaiti: when drafting or revising a manuscript with me, follow
`writing/HOW_TO_WRITE_A_GOOD_PAPER.md` — architecture before prose, one-pass Introduction,
theorem → proof → interpretation → limitation, machinery to the Appendix, the seven-pass revision
workflow, and precisely scoped formalization claims. Its §13 is a reusable review prompt.
